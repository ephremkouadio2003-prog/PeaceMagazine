# 🔐 Comment entrer votre mot de passe dans le Terminal

## ⚠️ IMPORTANT : Le terminal ne montre PAS votre mot de passe !

C'est **NORMAL** et c'est pour votre **SÉCURITÉ**.

---

## 📝 Instructions étape par étape

### Étape 1 : Vous voyez ce message
```
Password:
```
ou
```
[sudo] password for ephremkouadio:
```

### Étape 2 : TAPEZ votre mot de passe
- **Tapez votre mot de passe macOS** (celui que vous utilisez pour déverrouiller votre Mac)
- **Ne vous inquiétez pas** si vous ne voyez rien à l'écran
- **Ne voyez pas d'astérisques (*)** ou de points (•) ? C'est normal !
- **Le curseur ne bouge pas** ? C'est normal aussi !

### Étape 3 : Appuyez sur ENTRÉE
- Une fois que vous avez tapé votre mot de passe
- Appuyez sur la touche **Entrée** ou **Return**
- Si le mot de passe est correct, l'installation continuera
- Si le mot de passe est incorrect, vous verrez "Sorry, try again" et vous pourrez réessayer

---

## 💡 Exemple visuel

```
ephremkouadio@MacBook-Air-de-Ephrem Peace magazine % brew install node
Password: [VOUS TAPEZ ICI MAIS RIEN N'APPARAÎT]
```

**Vous tapez** : `monmotdepasse123`  
**Vous voyez** : Rien du tout (c'est normal !)  
**Vous appuyez** : Entrée  
**Résultat** : L'installation commence ✅

---

## 🆘 Si ça ne fonctionne pas

### Problème : "Sorry, try again"
→ Votre mot de passe est incorrect. Réessayez.

### Problème : Vous n'arrivez pas à taper
→ Cliquez dans la fenêtre du Terminal pour vous assurer qu'elle est active.

### Problème : Vous préférez ne pas utiliser le terminal
→ Utilisez l'**Option 1** du fichier `INSTALLATION-SIMPLE.md` (installation via le site web)

---

## ✅ Alternative : Installation sans terminal

Si vous préférez éviter complètement le terminal pour le mot de passe :

1. Allez sur https://nodejs.org/
2. Téléchargez le fichier .pkg
3. Double-cliquez dessus
4. Entrez votre mot de passe dans la fenêtre graphique de macOS (plus facile !)

---

**Astuce** : Si vous avez des doutes sur votre mot de passe, testez-le d'abord en essayant de déverrouiller votre Mac. Si ça fonctionne, c'est le bon mot de passe !
