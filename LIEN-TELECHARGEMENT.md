# 📥 Lien de téléchargement de Node.js

## 🎯 Lien direct vers le site officiel :

### **https://nodejs.org/**

---

## 📋 Instructions étape par étape :

1. **Cliquez sur le lien** : https://nodejs.org/

2. **Sur la page d'accueil**, vous verrez deux boutons :
   - **Bouton vert "LTS"** (Long Term Support) ← **CHOISISSEZ CELUI-CI**
   - Bouton gris "Current" (version actuelle)

3. **Cliquez sur le bouton vert "LTS"**

4. **Le téléchargement commence automatiquement**
   - Le fichier s'appellera quelque chose comme : `node-v20.x.x.pkg`

5. **Une fois téléchargé** :
   - Allez dans votre dossier **Téléchargements**
   - **Double-cliquez** sur le fichier `.pkg`

6. **Suivez l'assistant d'installation** :
   - Cliquez sur "Continuer" plusieurs fois
   - Acceptez les conditions d'utilisation
   - **Entrez votre mot de passe macOS** : `Juillet2003@`
   - Cliquez sur "Installer"

7. **Redémarrez votre Terminal** (fermez-le et rouvrez-le)

8. **Vérifiez l'installation** :
   ```bash
   node --version
   npm --version
   ```

---

## ✅ C'est tout !

Après l'installation, vous pourrez utiliser npm et node dans votre terminal.
